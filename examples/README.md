# Examples

Run `npm run render` and copy one artefact of each kind here for reviewers
who would rather not run anything:

- `box-email.html` + `box-email.txt` — the weekly box email and its plain text
- `box-page.html` — the public box page
- `packing-slips.pdf` — the packing document as a PDF
- `recipe-card.png` — the recipe card (needs the fonts in `assets/fonts/`)

Generated files are build outputs (`out/` is git-ignored); the copies in
this folder are the committed, reviewable examples.
